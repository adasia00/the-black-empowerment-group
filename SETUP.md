# Setup

## Prerequisites

- Node.js 18 or later
- npm

## Development

From the project root:

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000). The site includes Home, Services, and Contact Us routes.

## Production

```bash
npm run build
npm start
```

The inquiry form is a front-end preview only. Configure a submission service before using it to receive real messages.
